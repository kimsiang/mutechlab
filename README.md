# mutechlab · 缪子科技实验室

Website for the Muon Technology Laboratory (缪子科技实验室), Tsung-Dao Lee Institute, Shanghai Jiao Tong University.

Single static page, bilingual (中文 / English), no build step.

## Structure
- `index.html` — the whole site (styles and scripts inline)

## Sections
1. Hero — cosmic-ray muons falling through the page
2. 天然缪子 / What a muon is
3. 研究方向 / Four research pillars (g-2, EDM, SHINE muon source, muography)
4. 缪子成像原理 / How muography works + survival-vs-depth chart
5. 应用场景 / Where muography helps
6. 科普实验室 / Interactive depth calculator
7. 新闻 / News
8. 合作 / Collaborate & contact

## Local preview
Open `index.html` in a browser, or `python3 -m http.server`.

## Deploy
Push to GitHub and enable Pages (Settings → Pages → main / root).
